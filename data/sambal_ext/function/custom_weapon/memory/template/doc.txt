Projectiles structure :
Abilities Usage:
# These are automatically done with built in cooldown for click right click drop and swap cooldowns all configurable with an base one for template
When activating automatically activates through ID and type and method into their respective paths :
for example u left_click with the left click ability of template it runs function sambal_ext:custom_weapon/memory/template/left_click/1/play
which u can then call the spawning
The 1 is the variation stated in the data of the item
->
spawning : 
# Automatically paths to type and id just manual id but these id can be called within the activation function
    sambal_ext:custom_weapon/projectile/drop_item_spawn
    sambal_ext:custom_weapon/projectile/left_click_spawn
    sambal_ext:custom_weapon/projectile/right_click_spawn
    sambal_ext:custom_weapon/projectile/swap_item_spawn
hitting :
# executer is the entity hit, this automatically paths's to the method and id and type 
    function sambal_ext:custom_weapon/projectile/hit_entity

Basically a more data driven item structure and function pathing that could work for configurable and customizable abilities
